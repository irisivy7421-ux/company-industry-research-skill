# 总览画板 SVG 规范

本目录提供跨平台视觉规范，不假定目标平台已经安装任何同名 Skill。先阅读 `RULES.md` 和 `CATALOG.md`，根据公司气质、内容密度和阅读场景选择一个模板，再读取对应的 `templates/<style>/design.md`。

## 画布与层级

- 默认使用 16:9 横向画布，建议 `1600 × 900`；信息较复杂时可以扩大尺寸，但保持横向阅读。
- 使用 `<g>` 将每个独立视觉区域分组。组内先放背景，再放线条、图形和文字。
- 保留 SVG 文本节点，不把全部文字转为路径，以便后续编辑和检索。
- 使用系统常见中文字体回退，避免依赖目标平台不存在的字体。

## 内容组织

- 一个明确的中心判断作为视觉锚点；
- 业务引擎、经营质量、行业位置、增长边界形成可顺序阅读的闭环；
- 关键数据必须带口径或时间，未知信息明确标识；
- 少用交叉连线，不能依赖颜色作为唯一语义；
- 每个模块表达一个判断，不把报告段落缩小粘贴进画板。

## 验收

生成后必须实际渲染或打开查看，检查：

1. 100% 视图和缩略图状态下都能识别主标题与中心判断；
2. 没有文字溢出、遮挡、断行异常或背景盖住内容；
3. 四类必需信息均出现；
4. 关键数字和证据边界清晰可见；
5. 若导入飞书，检查飞书实际预览，而不是只检查本地 SVG。
