# 证据规则

## 来源优先级

优先用离结论最近、可追溯的来源。对上市公司，优先年报、季报、招股书、业绩会实录、投资者演示和监管披露；对非上市公司，优先官网、官方新闻稿、招聘与产品文档、权威采访及可识别的客户材料。行业规模、份额、政策和竞争关系应尽可能用独立机构、监管机构、行业协会或原始数据验证。

媒体报道可用于发现线索和时间线，但不应独自支撑重大经营结论。咨询或券商报告可用于行业观点，须保留其统计口径与发布时间。搜索摘要、无署名转载和不可访问的付费内容不能作为核心事实来源。

## 证据卡格式

每个影响中心判断的主张使用以下最小记录：

| 字段 | 内容 |
|---|---|
| 主张 | 可被验证的具体表达 |
| 类型 | 事实 / 推断 / 待验证 |
| 证据 | 来源名称、链接、发布日期或数据期间、页码/章节/原文段落 |
| 口径 | 主体、地区、业务范围、币种、统计方法（如适用） |
| 含义 | 这项证据如何支持或限制中心判断 |
| 置信度 | 高 / 中 / 低，以及原因 |

数字不可脱离单位、时间和口径。若比较两个数字，先确认会计准则、合并范围、统计对象和时间区间是否一致。

## 三层表达

- **事实**：来源直接陈述或可由公开原始数据复算的内容。例如“公司披露某财年收入为 X”。
- **推断**：从两个以上事实推出的经营解释。例如“收入增速与渠道扩张同时出现，渠道可能是增长动力之一”。
- **待验证**：合理但没有足够公开证据的假设。例如“高迁移成本可能驱动留存”；列出所需的验证材料。

不要用“显示、证明、必然、龙头、唯一”等绝对词替代证据。没有可比数据时，描述观察到的现象与边界。

## 冲突处理

来源冲突时，优先原始披露与时间更近、口径更清楚的材料；不要静默选择最符合既定叙事的一方。保留冲突、解释可能的口径差异，并降低结论置信度。

对于无法确认的关键事实，停止扩写相关结论，并在“待验证问题”中指定下一步应查的文件、人物或数据。
