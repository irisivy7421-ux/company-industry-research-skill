# 交付契约

## 对话摘要

无论使用哪种交付通道，最终对话都先提供：

- 一句话中心判断；
- 3–5 条关键事实或数字；
- 核心经营矛盾；
- 一个反证、限制条件或主要风险；
- “可以讲、谨慎讲、不能讲”的边界；
- 完整报告与画板的真实链接或文件。

对话摘要不是完整报告的重复粘贴。

## 文档

文档标题必须是客观陈述，不使用问题句。总览画板放在 30 秒结论之后。正文要能脱离对话单独阅读，来源应靠近主张，并注明发布日期或数据期间。

## 总览画板

快速版和深度版都制作一张总览画板，围绕中心判断组织 4–6 个视觉模块，覆盖：

1. 业务引擎；
2. 经营质量或商业化信号；
3. 行业位置与外部压力；
4. 增长命题和证据边界。

画板通常使用 3–6 个数字或事实锚点。它不是章节目录、卡片堆叠或普通流程图；不得为了极简只保留口号。默认只制作一张，只有独立的第二问题确实无法并入总览时才增加第二张。

### 飞书文档中的画板硬门槛

1. 在开始研究前创建飞书文档和画板占位，或确定会在文档正文中插入 SVG 画板的具体工具与方法。把文档 URL 和 board token 作为本次任务状态持续保存。
2. 报告写入时，将非空画板放在“30 秒结论”之后。可用独立白板工具写入先前保存的 token；若平台只支持文档创作接口，则在文档内容中插入完整 SVG 白板块。不可只附 SVG 文件而让飞书正文没有总览图。
3. 写完后回查文档正文，确认白板块存在且包含图形内容；导出白板实际预览并查看。空白白板、只创建文档、只保存本地 SVG、只在对话中贴预览，都不算画板交付。
4. 若确认平台不能写入飞书白板，生成完整 SVG 并保存，尽可能把渲染后的 PNG 插入文档；最终显式标记“飞书画板未写入”，说明限制，并链接 SVG/PNG。该路径是降级交付，不得标成画板已完成。

## 完成标准

链接或文件真实存在只是最低标准。还必须检查标题、关键数字、中心判断和边界是否可见，文字是否溢出或过小，飞书节点是否被背景遮挡。画板区必须有内容而非占位框。未经实际查看，不得声称“画板已预览”。
